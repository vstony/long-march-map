# 红军长征全景交互地图

单文件 HTML 交互地图应用（`index.html`），基于腾讯地图 GL JS，浏览器直接打开即可使用。

**在线访问（GitHub Pages）**：<https://vstony.github.io/long-march-map/>

## 功能

- **四路红军**：红一方面军（中央红军）、红四方面军、红二方面军（红二、六军团）、红二十五军，分色路线与路线节点，按时间轴（1934.09 — 1936.10）动态展示
- **番号序列**：每路红军的完整建制序列（军团 / 军 / 师及主要指挥员、兵力、任务），并附番号演变时间线（整编、会师、改称）
- **重大事件**：75 个事件节点（湘江战役、遵义会议、四渡赤水、飞夺泸定桥、三大主力会师等），点击弹出详情
- **国民党军部署**：40 条围堵部署——四道封锁线、追剿军及川滇黔粤桂湘各派系、东北军、晋绥军、宁马等；蓝色实心箭头＝进攻/追击方向，灰蓝线＝封锁线，菱形＝指挥部/要地，均随时间轴窗口过滤
- **主要江河**：于都河、湘江、乌江、赤水河、金沙江、大渡河、嘉陵江、长江、黄河示意河道与江名标注
- **交互**：选中部队显示同色光晕、时间轴播放/拖动、图层开关（事件点、地名标签、光晕、国军、江河）、来源参考页

## 数据说明

路线、番号、事件与国军部署数据依据人民网党史频道等公开权威资料整理；河道为示意画法（按今地名取点），非精确水系。坐标已内置 WGS-84 → GCJ-02 转换。

## 使用

无需构建，直接用浏览器打开 `index.html`（需联网加载地图 SDK），或访问上面的在线地址。桌面端与移动端均已适配。
